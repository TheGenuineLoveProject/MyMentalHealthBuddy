# Platform Constitution

## Mission
The Genuine Love Project and MyMentalHealthBuddy shall prioritize user safety, reliability, dignity, accessibility, evidence-informed education, privacy, and measurable user benefit.

## Primary Engineering Rule
Stability before expansion.

## Core Rules
1. Do not claim completion without verification.
2. Do not mix healing flows with monetization logic.
3. Do not replace therapy, diagnosis, legal, or medical care.
4. Do not store unnecessary sensitive data.
5. Do not create duplicate entrypoints.
6. Do not refactor working code without a verified reason.
7. Every production feature must have verification evidence.
8. Every user-facing healing feature must be trauma-informed, accessible, and educationally framed.
9. Every monetized feature must be transparent and non-coercive.
10. Every failure in auth, billing, biometrics, backup, safety, or deployment must be observable.

## Completion Standard
A component is complete only when it is:
- implemented
- documented
- verified
- observable
- recoverable
- aligned with safety rules
