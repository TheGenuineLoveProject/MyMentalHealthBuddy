# Architecture Decisions

## ADR-001: PEOS must remain isolated
PEOS governance must be added as documentation, registry, and verification infrastructure before runtime logic.

## ADR-002: Healing and business separation
Healing flows must not directly contain monetization pressure, crisis upsells, or manipulative engagement logic.

## ADR-003: Adaptive development program is educational
The 21-day Adaptive Human Development Program is educational, reflective, and practice-based. It must not promise guaranteed transformation.

## ADR-004: Evidence transparency
Each lesson, affirmation, reflection, assessment, and behavioral experiment must include evidence classification and confidence estimate.
